# SOC Home Lab
 
Hands-on Security Operations Center (SOC) practice covering infrastructure build, log pipeline configuration, SIEM onboarding, and detection engineering.
 
## What's inside
 
### [`microsoft-sentinel-lab/`](./microsoft-sentinel-lab)
A complete Microsoft Sentinel SOC lab built manually in Azure — Windows and Linux VMs feeding a shared Log Analytics workspace, onboarded to Microsoft Defender and Sentinel, with custom KQL analytics rules detecting brute-force and credential-access activity across RDP, SSH, and Entra ID sign-ins. Includes a full troubleshooting write-up covering log pipeline debugging, RBAC issues, and NSG/network access conflicts.
 
**Skills:** Azure infrastructure, Microsoft Sentinel & Log Analytics, KQL, detection engineering, MITRE ATT&CK mapping, systematic troubleshooting.
